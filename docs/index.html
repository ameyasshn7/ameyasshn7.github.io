I'm a Ph.D. student at Oregon State University, advised by Dr. Jing Zhou and Dr. Fuxin Li. I build low-cost computer vision systems that run on edge devices like the Raspberry Pi and NVIDIA Jetson, and I take them out to farms to monitor crops and pests in places where power and connectivity are limited.

Right now that means a network of field cameras watching for slugs in Willamette Valley grass seed fields, a camera system that helps seed analysts identify grass seed species, and a multimodal sensor suite (RGB, NIR, thermal and point hyperspectral) for detecting plant stress.

Research

Slug monitoring in grass seed fields

48 semi-autonomous camera systems and 12 weather monitoring units built on Raspberry Pi 4, ESP32 and Pi Camera NoIR modules, with a one-week battery life, deployed in Willamette Valley grass seed fields. An optical-flow-based network detects slug movement, and I pair its predictions with the weather data to understand what drives slug emergence.

Grass seed species identification

A camera system that helps seed analysts identify grass seed species, with custom camera software for Raspberry Pi and NVIDIA Jetson Orin Nano, a tuned image acquisition pipeline and server-side inference. I benchmarked several cameras using libcamera, GStreamer and GenICam. The project was recognized by the Oregon Seed Association.

DIRT: Data-driven Inference of Rootzone and Terrain

With the OPEnS Lab (Dr. John Selker), funded and supported by Stevens Water. A sensor suite combining RGB, NIR, LWIR and point hyperspectral sensors, a transformer-based multimodal model that detects multiple stressors on a golf course, and a method to reduce infrared leakage in RGB sensors.

Grady Sensor web application

A full-stack web app (Node.js, React, Stripe) for the Grady Sensor grass-seed moisture monitoring system, supporting technology transfer and commercial deployment.
